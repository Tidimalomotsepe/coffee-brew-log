\# Coffee Brew Log



\## Description



Coffee Brew Log is a full-stack web application for recording and managing coffee brews.



The application allows users to:



\- Create a new brew

\- View saved brews

\- Filter brews by brewing method

\- Edit an existing brew

\- Delete a brew

\- Rate brews from 1 to 5

\- Record coffee and water quantities

\- Record tasting notes



\## Technology Stack



\### Frontend



\- React

\- Vite

\- Bootstrap

\- CSS



\### Backend



\- Node.js

\- Express



\### Database



\- SQLite

\- Prisma ORM
