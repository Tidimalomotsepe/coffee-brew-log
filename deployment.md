\# Deployment



\## Backend Deployment



The Coffee Brew Log backend is deployed using Render.



\### Backend URL



https://tidimalo-coffee-brewlog.onrender.com



\### API URL



https://tidimalo-coffee-brewlog.onrender.com/api/brews



\## Backend Configuration



The backend runs as a Node.js/Express application.



Environment variables are configured through the hosting provider and are not committed to the repository.



The repository includes `backend/.env.example` as a template for local configuration.



\## Local Backend Testing



The backend was tested locally using:

cd backend

node server.js
